# Neural Networks - MNIST MLP Project

## Problem Description
This project implements a Multilayer Perceptron (MLP) model for handwritten digit classification using the MNIST dataset, The goal is to analyze the effect of different hyperparameters such as activation functions, number of neurons, and learning rates on model performance 

## Dataset Link
http://yann.lecun.com/exdb/mnist/

## Results
| Experiment | Test Accuracy (%) | Test Loss |
| ---------- | ----------------- | --------- |
| Exp 1      | 97.36             | 13.45     |
| Exp 2      | 97.20             | 14.19     |
| Exp 3      | 93.05             | 38.31     |
in addition of a confusion matrix and the train and val
